# PreçoCerto

[![License](https://img.shields.io/github/license/ThiagoSanTh/PrecoCerto)](https://github.com/ThiagoSanTh/PrecoCerto/blob/main/LICENSE)  
[![Build Status](https://img.shields.io/github/actions/workflow/status/ThiagoSanTh/PrecoCerto/ci.yml?branch=main)](https://github.com/ThiagoSanTh/PrecoCerto/actions)

**PreçoCerto** – plataforma de comparação e recomendação de preços para consumidores brasileiros.  
Interface limpa, tipografia moderna (Poppins), paleta azul‑verde (`#00695c` / `#00bfa5`) e componentes reutilizáveis.

---

## 📦 Instalação

```sh
# clone o repo
git clone https://github.com/ThiagoSanTh/PrecoCerto.git
cd PrecoCerto

# instalar dependências (Node.js >= 18)
npm ci   # usa lockfile

# rodar em modo desenvolvimento
npm run dev
```

O app será servido em `http://localhost:3000`.

---

## 🚀 Uso

1. Abra a aplicação no navegador.
2. Digite o nome do produto ou cole a URL do marketplace.
3. Compare preços de diferentes vendedores.
4. Clique em **Selecionar Melhor Oferta** para abrir a página do vendedor.

> **Dica**: habilite o modo escuro nas configurações para reduzir fadiga visual.
